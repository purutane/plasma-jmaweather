# 気象庁天気予報 (plasma-jmaweather)

気象庁の予報データをそのまま表示する KDE Plasma 6 用ウィジェットです。海外の気象サービス
を経由せず、`www.jma.go.jp` が配信している府県天気予報・週間天気予報を直接読みます。

> A KDE Plasma 6 applet showing the Japan Meteorological Agency forecast. Japanese regions only.

## できること

- **パネル常駐** — 天気アイコンと気温（`29°/23°`）をパネルに表示。降水確率のみ、気温と降水確率の
  併記、アイコンのみにも切り替えられます
- **クリックで展開** — 大きな天気アイコン、気象庁の天気文、最高最低気温、これからの降水確率
  （6時間ごと）、週間予報7日分、府県ごとの概況テキスト
- **全国 58 予報区 / 142 地域** に対応。「千葉県 - 北西部」のように予報区名を冠して表示します
- 中クリックまたは右クリックメニューで即時更新。既定の更新間隔は 30 分

## 動作環境

- KDE Plasma 6（Qt 6）
- ネットワーク接続。外部ライブラリや API キーは不要です

## インストール

```sh
git clone https://github.com/purutane/plasma-jmaweather.git
cd plasma-jmaweather
kpackagetool6 --type Plasma/Applet --install .
```

更新するときは `--upgrade .` に変えて同じコマンドを実行します。削除は次の通りです。

```sh
kpackagetool6 --type Plasma/Applet --remove org.kde.jmaweather
```

インストール後、ウィジェット一覧に出てこない場合は plasmashell を読み込み直してください。

```sh
kquitapp6 plasmashell && kstart plasmashell
```

あとはパネルを右クリック →「ウィジェットを追加」→「気象庁天気予報」を選びます。

### 開発時

作業ツリーをそのままインストール先に見せると、編集がすぐ反映されて楽です。

```sh
ln -s "$PWD" ~/.local/share/plasma/plasmoids/org.kde.jmaweather
```

単体で起動して確認できます。

```sh
plasmawindowed org.kde.jmaweather
```

## 設定

ウィジェットを右クリック →「気象庁天気予報を設定」から変更できます。

| 項目 | 内容 |
| --- | --- |
| 予報区 / 地域 | 全国 58 予報区とその一次細分区域 |
| パネルの表示 | アイコンのみ / 気温 / 降水確率 / 気温と降水確率 |
| 地域名 | パネルにも地域名を併記するか |
| 更新間隔 | 5〜360 分（既定 30 分） |

## データについて

出典は気象庁です。`bosai` 配下の JSON をそのまま読んでいます。

- 府県天気予報: `https://www.jma.go.jp/bosai/forecast/data/forecast/{予報区コード}.json`
- 府県概況: `https://www.jma.go.jp/bosai/forecast/data/overview_forecast/{予報区コード}.json`
- 予報区一覧: `https://www.jma.go.jp/bosai/common/const/area.json`

短期予報は 1 日 3 回（5時・11時・17時頃）、週間予報は 1 日 2 回更新されます。それより短い間隔で
取りに行っても内容は変わりません。

これらは気象庁のウェブサイトが内部的に使っているもので、仕様が公表された API ではありません。
予告なく形式が変わる可能性があります。利用にあたっては
[気象庁ホームページについて](https://www.jma.go.jp/jma/kishou/info/coment.html) を確認してください。

## 実装メモ

気象庁の JSON は素直に読めない箇所があり、全国分の実データで確認しながら対応させています。

- **週間予報は区域のくくりが粗い** — 短期予報の「中通り」「浜通り」が週間では「中通り・浜通り」に
  まとまるなど、149 区域中 133 件でコードが一致しません。単純に並び順で対応させると根室・浜通り・
  伊豆諸島南部・大隅・種子島屋久島の 5 箇所が別地域の予報を拾ってしまうため、「短期側に存在しない
  コードを持つ週間区域＝受け皿」へ寄せています。全 58 予報区で受け皿が一意に定まることを確認済みです
- **気温は観測所単位** — 短期予報の気温は天気の区域と数が合いません（福島県は 3 区域に対し 7 観測所）。
  週間予報側の観測所コードが短期側にも必ず存在することを利用して、そこを鍵に引いています
- **配信コードの例外** — 十勝 (014030) と奄美 (460040) は `area.json` のコードでは 404 になるため、
  それぞれ 014100 / 460100 へ読み替えます
- **夕方以降は今日の気温が消える** — 17 時発表以降、今日の最高・最低気温は配信対象から外れます。
  その場合は主表示を翌日に繰り上げ、見出しに「明日」と出します
- **天気コード** — 気象庁の 118 コードを Breeze の天気アイコンへ対応させています。夜間は今日を
  表示しているときだけ夜アイコンに切り替わります

## データファイルの再生成

`contents/code/Areas.js` と `contents/code/Telops.js` は気象庁のサイトから生成したものです。
区域の再編や天気コードの追加があったときは次を実行します。

```sh
python3 tools/generate_data.py
```
